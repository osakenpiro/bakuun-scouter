# バク運スカウター / Bakuun Scouter

**Live: https://osakenpiro.github.io/bakuun-scouter/**

運を「勝った/負けた」のBooleanでなく、連続値Floatで計測する運力計測器。

- **戦闘力** = (1/p)^n × 貯金倍率 — 確率の逆数で連勝の希少さを測る
- **bit** = n × log2(1/p) — 底の違うゲームを公平比較する情報量(純粋値)
- **運Float** = 1 − p^n — 1.0は仕様として存在しない
- **バースト** = 記録に残らない。ゼロ。確定だけが記録になる(ヤメ時判断=内面がスコア)
- **運の貯金** = 遊ばない日々に+0.2/日で溜まり(上限1.0)、次の挑戦の戦闘力倍率(×1.0〜×2.0)になって消費される放置メカニクス

姉妹企画 🎲ドラコロバトル(ボードゲーム・育成中)と運哲学「運ゲーは理不尽でも、運も欲しい」を共有。
